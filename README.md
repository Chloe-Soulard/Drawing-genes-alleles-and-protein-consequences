# Alleloscope

Create figures and predict protein consequences for your mutated alleles.

Copy-paste your gene sequence, add annotations about where the exons are and the nature of the mutation, and it will compute the consequence on the protein and draw it.

**Use it live, nothing to download:** https://chloe-soulard.github.io/tools/alleloscope.html
(all my tools are on my website: https://chloe-soulard.github.io/tools/)

Or download `Allele_figure_builder.htm` to use it offline. The page opens on a made-up example gene, and `example_project.txt` is the same example saved as a project file (open it with the "Open project (.txt)" button).
